ACF WordPress Gutenberg block that shows what book the author is currently reading.

== Description ==

Watch a brief video feature presentation here where I showcase the main features: [What I'm Reading - Wordpress Plugin - Feature Presentation](https://youtu.be/hHB3TX7Prdw)

== Installation ==

Get the latest .zip release file from *Releases* on [GitHub](https://github.com/rmysliwczyk/what-im-reading-wp-gutenberg-block) and install it in your WordPress admin panel.
